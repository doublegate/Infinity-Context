# Phase 3 — Hyperdimensional (`HDC`), Fractal (`FCGA`) & Bi-Temporal Graph Index

## Goal

Implement the sub-50µs **10,240-Bit Hyperdimensional Computing (`HDC/HRR`)** associative engine, **Fractal Chaos-Game Trajectory Archive (`FCGA`)**, **Titans Surprise-Gated Momentum Tracker** (`crates/icx-hdc`), and **Bi-Temporal CSR Knowledge Graph + HippoRAG Personalized PageRank (`PPR`)** (`crates/icx-store`).

## Exit Criteria

- [x] `Hypervector` (`[u64; 160]`) supports deterministic BLAKE3 XOF seeding, XOR binding, circular permutation, Delta-Rule majority bundling, and POPCNT similarity search.
- [x] `FractalCoord` (`[-1.0, 1.0]^16`) computes exact shared suffix depth in $O(1)$ time via Chebyshev distance.
- [x] `TitansSurpriseGate` tracks surprise momentum $S_t$ and boosts anomaly retention.
- [x] `BiTemporalGraph` auto-invalidates superseded functional edges (`t_invalid`) and executes multi-hop Personalized PageRank (`PPR`).
