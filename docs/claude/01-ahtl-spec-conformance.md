### ICX-AUD-030 — The normative PDF is stale and self-contradictory about its version (Medium)

- **Claim:** "AHTL v1.0 Complete Technical Specification Volume" (cover). `to-dos/ROADMAP.md`
  Phase 2 says the code was cross-referenced against it.
- **Reality:** Chapter 08 documents the v0.3.0 data model, not the shipped one. The cover's
  hard-coded claims are not regenerated from the chapters.
- **Impact:** Any reader treating the PDF as the specification implements the wrong field set and
  parser arity.
- **Remediation:** Generate the cover and TOC claims from the Markdown, not inline HTML. Make the
  PDF a build artifact checked in CI: rebuild it and fail if `git diff --exit-code` is non-empty.
  Alternatively, stop committing the 19 MB PDF and publish it as a release asset.

## 3. Reproduced defects

### ICX-AUD-024 — Epoch headers are written in decimal and parsed as hex (Low, latent)

PoC (`seal_epoch` then `EpochHeader::parse`):

```text
seal_epoch(10)    header = ⟪ICX:v1│ep=0010│root=39b25e0c│nodes=1⟫  -> parse epoch_id = 16
seal_epoch(10000) header = ⟪ICX:v1│ep=10000│root=cf709ef2│nodes=1⟫ -> Err(MalformedEpochHeader)
```

- **Status:** no production code parses DAG-emitted headers yet (`EpochHeader::parse` has no
  callers outside `ahtl.rs`), so this is latent. It becomes live as soon as a consumer
  re-reads headers, and a model reading `ep=0010` cannot tell the two conventions apart.
- **Fix:** write `{epoch_index:04x}` in `dag.rs:736`, or change the grammar to decimal. Widen past
  4 digits or document the wrap at 65,535.
- **Regression test:** `seal_epoch(n)` → `EpochHeader::parse` must return `n` for
  n ∈ {0, 9, 10, 15, 16, 255, 65535}.

### ICX-AUD-025 — Unescaped `slice_hint` allows stream-level packet forgery (Low, latent)

`AhtlPacket::parse(render(p)) == p` holds for adversarial hints, because the parser splits from the
right. The pre-audit lead "not bijective" is therefore **wrong at the packet level**. At the
*stream* level, `AhtlStream::parse_stream` splits on the first `⟧`. A hint carrying `…⟧\n⟦Ω:…⟧`
therefore produces an extra, forged `Invariant` packet (`⟦Ω:forged⊢admin:true…⟧`).

- **Reachability:** `slice_hint` is only populated by `parse()` and by tests. Exposure is limited
  to parse → re-render relays, which no current code path performs.
- **Fix:** validate `slice_hint` against the `SliceMap` production at construction and in parse, or
  percent-escape it like clauses.
- **Regression test:** property test asserting that `parse_stream(render(p))` yields exactly one
  packet equal to `p` for arbitrary `slice_hint: String`.

### ICX-AUD-026 — Unbounded recursion in `AhtlClause::parse` aborts the process (Low)

A clause chain of `k⇒k⇒…` parses at 100,000 links but aborts at 200,000 links, which is about
600 KB of input. The abort (`fatal runtime error: stack overflow, aborting`) happens on the 8 MB
main stack and cannot be caught. `icx decode-ahtl` is protected only incidentally, by `ARG_MAX`
(a 40k-link argument already fails with `E2BIG`). The library API, and any future stdin or MCP
path, is exposed.

- **Fix:** iterative parse with a maximum chain depth (for example 64), returning
  `CodecError::ChainTooDeep`.
- **Regression test:** 1,000,000-link chain returns `Err` within a 2 MB thread stack.

## 4. Exactness-review cross-check (`ref-docs/ahtl-exactness-review-and-analysis.md`)

The review marks all seven "minimum exactness standards" as **ENFORCED** (§2.5, `:188-196`).
Audit verdicts:

| Standard | Review verdict | Audit verdict |
| --- | --- | --- |
| Commit to CAS before skeletonizing | ENFORCED | Holds, but what is committed is the **sanitized** text, not the raw bytes (ICX-AUD-021) |
| Verify the full 256-bit digest | ENFORCED | Holds for `deref_bytes`; but `mmu.rs:585-588` falls back to unchecked `put_bytes` on *any* error, including a collision (ICX-AUD-022) |
| Ambiguous short handles fail closed | ENFORCED | Holds (`cas.rs:106-113`) |
| Pinned round-trip tests | ENFORCED | Packet-level only; no stream-level, property or fuzz tests (ICX-AUD-039) |
| CAS durability / access control independent | ENFORCED | Not met: the workspace is a repo-relative directory with no ownership or trust check (see `05-security-findings.md`, ICX-AUD-010) |
| Retrieval separated from authoritative recovery | ENFORCED | Partially; recall output and deref output carry no untrusted-content provenance (ICX-AUD-011) |
| Adversarial test coverage | ENFORCED | Not met (ICX-AUD-039) |

The review also contradicts itself:

- **ICX-AUD-032 (Low):** §2.2.5 (`:95`) says clauses are unescaped, while §2.5 (`:193`) says
  escaping is enforced.
- **Wrong figure:** the 48-bit birthday figure (`:82`, "≈1.18×10⁷ (≈2^24.5)") is wrong. The 50%
  point is 1.1774·2^24 ≈ **1.98×10⁷**; 2^24.5 is 2.37×10⁷.
- **Unresolved items under "ENFORCED":** several items raised in §2.3.4 and §2.4 have no recorded
  resolution yet are covered by the blanket "ENFORCED": diff misrouting on `: error TS`, the
  brace scanner missing block comments, standalone 64-hex secrets, split tokens, `FAIL@L`
  functional keys, and the writer spin-drop.
- **Inconsistent line citations:** the same function is cited at different lines in different
  sections (`mmu.rs:342-357` vs `744-760`, `cas.rs:202-225` vs `256-282`).

## 5. Items that could not be verified

- **BPE alignment:** "each delimiter is a single BPE token" for Anthropic models (ch07) needs the
  Messages token-counting API with a key, so it was not run. Treat the claim as unverified.
- **Test vector 1:** its BLAKE3 digest (`4f3598d9…`) was not recomputed independently. The codec's
  own test reproduces it, but that test is self-referential.

## 6. Recommendations

1. Make the ch01 EBNF the single normative grammar. Generate parser test vectors from it, and add
   every emitted header kind (`STUB`, `TAIL_SLOT`, `PROVENANCE`, …) as a production.
2. Fix all documentation examples to valid 12- or 16-hex handles, and add a doc test that
   extracts every `⟦…⟧` / `⟪…⟫` sample from `docs/**/*.md` and parses it.
3. Replace "bijective" with a precise statement. Escaping is bijective *for clause keys and
   values*; Tier-0 delimiter replacement (`⟪→<<`) is lossy and non-injective (ICX-AUD-021).
4. Add `proptest` round-trip properties for packet, stream, epoch-header and Braille layers, and a
   `cargo fuzz` target for `AhtlStream::parse_stream` and `WirePacket::parse_auto`.
