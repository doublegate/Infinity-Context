## Corrections to the audit itself

- **ICX-AUD-003:** the proxy's folded history turned out to be byte-stable across turns (verified by test in `crates/icx-proxy/tests/cache_placement.rs`). The claim that it "rewrites cached history every turn" was overstated; the real defects were client-breakpoint stripping and message-level placement, both fixed.
- **ICX-AUD-002:** including seal turns changed the synthetic figure only slightly (95.38% to 95.46% byte-weighted). The benchmark still uses the same synthetic transcript with its large static prefix, so the number remains a property of that fixture; v1.1.0 labels it as a byte proxy rather than a cache hit rate, and real-transcript measurement is still to do.
