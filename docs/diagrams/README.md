# Current runtime diagrams (v1.2.0 candidate)

These Mermaid sources describe current contracts:

- [Five planes](five-plane-architecture.mmd): capture, storage, hybrid recall, bounded context and bus.
- [Runtime crate dependencies](crate-and-agent-relationships.mmd): arrows point from dependent to dependency; excludes dev dependencies.
- [Hook and daemon flow](synchronous-hook-and-shm-flow.mmd): adapter-specific responses and commit before successful daemon ACK.
- [Epoch lifecycle](cache-epoch-lifecycle.mmd): immutable cold history with budgeted selection and whole-frame tails.

[Graphviz relationship graphs](../../images/) are generated by `python3 scripts/generate_assets_and_graphs.py --graphs-only`. This mode does not require private branding source artwork and does not modify branding assets. The Graphviz labels and Mermaid templates are maintained in that script; the crate edges come from current Cargo manifests.

[SVG illustrations](../images/) have a separate source, `scripts/render_diagrams.py`; run it to regenerate SVGs, PNGs and their mirrors under `images/`. SVG metadata records the generator source digest and candidate label. These illustrations are summaries; the subsystem prose and [ADR 0006](../adr/0006-v1-2-0-context-and-compatibility.md) define the detailed contracts.

No diagram promises a provider cache-hit rate, fixed retrieval latency, native output replacement for Codex, or a bound on an entire provider request. See [dated measurement evidence and limits](../numbers.md); synthetic byte reuse is not measured provider billing/cache behavior or model-quality assurance.
