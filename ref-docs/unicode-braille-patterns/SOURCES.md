# Sources of the Unicode and ISO/IEC JTC 1/SC 2/WG 2 publications

Up to v1.1.0 this directory redistributed copies of the Unicode and WG2/UTC publications
below. Their Unicode-3.0 annotation covers Unicode data files, not these publications, so
from v1.2.0 they are no longer distributed (audit finding ICX-CODEX-071). Earlier
tags (including the v1.1.0 release source archives) and the git history still contain them. Each entry gives
the official source and the SHA-256 of the copy previously distributed here.

- **Verified source:** the official URL served a byte-identical file when checked on
  2026-11-21.
- **Register only:** no public URL serving the file was found; request the document by its
  number from the register listed. The SHA-256 identifies the exact copy this repository
  used, which remains in git history (`git show v1.1.0:<path>`).

The Unicode Character Database files in `standards-and-wg2/` (`Unicode_UCD_*.txt`) remain:
they are Unicode data files covered by the Unicode License v3.
